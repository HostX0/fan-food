# فن فود — المنيو والطلب

منيو عربي RTL بثمانية أقسام مصوّرة، بحث، مفضلة، وسلة ترسل الطلب إلى واتساب. يحتوي 58 صنفاً و73 خيار حجم وسعر، مطابقاً لملف `Fan_Food_Menu_Final.xlsx`.

## تحديث 21 سبتمبر 2026

- مدخل بالأقسام الثمانية باستخدام صور المنيو الاجتماعي، بدل المقدمة التسويقية الطويلة.
- كل صنف يظهر مرة واحدة. بطاقته تعرض الاسم والكمية والسعر؛ التفاصيل داخل نافذة الصنف.
- إضافة مباشرة للأصناف ذات الخيار الواحد، مع أزرار العدد بجانب السعر. الأصناف متعددة الأحجام تفتح اختيار الحجم.
- تصحيح كبة بتيتة جاب وكبة فن فود وقسم المسخن من الملف النهائي، مع الحفاظ على المعرّفات والأسعار.
- تحديث 11 صورة صنف: ثمان صور جديدة مستندة إلى لقطات إنستغرام المرفقة، وثلاث صور تشكيلات من المنيو الاجتماعي. بقيت صور باقي الأصناف.
- الصور المولّدة توضيحية. صورة كبة فن فود تشكيلة من قسم الكبة إلى حين تأكيد شكل الصنف الخاص.

## التشغيل والفحص

استخدم Node.js 22 وملف الاعتماديات المقفل:

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
npm start
```

ينتج البناء موقعاً ثابتاً في `out/`. لا توجد قاعدة بيانات أو تسجيل دخول أو بوابة دفع. بيانات العميل في ذاكرة الصفحة فقط؛ السلة والمفضلة محفوظتان محلياً.

## تعديل المنيو

- الأصناف والأسعار والصور: `src/data/menu.json`.
- رقم واتساب وروابط التواصل: `src/data/site.ts`.
- الواجهة والطلب: `src/components/menu-app.tsx`.
- تنسيق التحديث الحالي: `public/menu-practical-v7.css`.
- أصول الصور ومراجع التوليد: `docs/MENU_PHOTO_PROMPTS_V7.json`.
- لقطة مستقلة للمنيو النهائي: `tests/fixtures/final-menu-source.json`.

لا تغيّر معرفات الأصناف والأحجام عند تحديث الأسعار كي تبقى السلال المحفوظة صالحة. حجم البشاميل في Excel مكتوب «15 ألف»؛ يعرض الموقع «عائلي»، بسعر 15,000، مع اختيار لحم أو دجاج.

## الطلب والنشر

العميل يراجع سلتَه، يدخل بيانات التوصيل لبغداد، ويختار موقعاً على الخريطة اختيارياً. يفتح واتساب برسالة جاهزة، ويضغط إرسال بنفسه. أجور التوصيل والتوفّر وموعد التجهيز يؤكدها المطعم. لا يُرسل الموقع الطلب بصمت ولا يفرّغ السلة عند فتح واتساب.

تكامل Vercel الحالي ينشر `main` تلقائياً. تفاصيل النشر في `DEPLOY.md`. فحص المتصفح في `tests/browser-smoke.mjs` يغطي الأقسام والبحث والمفضلة والأحجام والعدد واستعادة السلة والتحقق ورسالة واتساب دون إرسال طلب.

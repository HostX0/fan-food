# تقرير التحقق — Fan Food

تاريخ الفحص: 2026-09-17.

## نطاق التحقق

**تم التحقق:** منطق JavaScript مستقل، ترابط بيانات الكتالوج والصور، ومعاينة واجهة المتصفح المجمّعة من نفس مكونات TSX ومنطق المشروع.

**غير متحقق:** تثبيت dependency tree الإنتاجي، فحص الأنواع الكامل، بناء Next.js، React 19 hydration، معالجة Tailwind للإنتاج، Google Fonts، نشر حي، أجهزة Safari/iOS الفعلية، أو وصول رسالة واتساب فعلية.

## 2. اختبارات معاينة الواجهة

**32/32 نجحت.** تفاصيل كل حالة في `browser-test-report.json`.

المقاسات المختبرة: 320×740، 390×844، 540×900، 768×1024، 820×1180، 1024×768، 1440×1000، 1920×1080. لم يظهر تجاوز أفقي لحدود الصفحة بهذه المقاسات؛ التمرير الأفقي داخل قائمة الأقسام مقصود.

السيناريو الرئيسي: دولمة لـ5 أشخاص، عبوتان ×26000 =52000، مع ملاحظة طلب ضلوع. إضافة كبة حلب 8000 تجعل مجموع الأصناف60000. التحقق من حقول فارغة، ثم إدخال بيانات اختبار، والتحقق من ظهور كل البنود والبيانات والتفاصيل في رابط واتساب بالرقم الصحيح. لم يُفتح الرابط لإرسال طلب. تم اختبار إزالة بند، وإلغاء تفريغ السلة ثم تأكيده، واختيار دجاج للمعكرونة، ورابط الفوتر.

اختبارات إضافية: عرض58بطاقة،10أزرار تصفية تشمل8أقسام، البحث العربي وبدائل الحروف، النتائج الفارغة، المفضلة، حصرTabداخل الحوار،Escape، وبقاء السلة بعد مراجعة الرسالة. لم تُرصد أخطاء JavaScript أثناء هذه السيناريوهات.

### القيود التجريبية

بيئة المتصفح منعت navigation إلى localhost وfile URLs بسياسة إدارية. استخدم Playwright `page.set_content()` لعرض ملف HTML مضمّن الأصول. تم استبدال localStorage بمخزن ذاكرة للاختبار في أصل صفحة معتم؛ هذا يؤكد serialize/read paths ضمن السيناريو، **وليس اختبار حفظ فعلي بعد إعادة فتح المتصفح**. استعادة البيانات وتنظيفها لهما اختبارات منطق مستقلة.

معاينة الاختبار تستخدم React16.0.0 وReactDOM16.0.1 المتاحتين محلياً، مع polyfill بسيط لـFragment، وتجميع TypeScript للواجهات الأصلية. نسخة الإنتاج تطلب React19.3.0 وNext16.3.5. لذلك تُصنّف النتائج كاختبارات **معاينة ومكونات ومنطق** لا كاختبارات إنتاج كاملة. ملفات مكتبات المعاينة القديمة مستبعدة من ملف مشروع Next.js المضغوط.

تم حظر طلب Google Fonts في الفحص لتجنب انتظار شبكة غير متاحة؛ لقطات الشاشة تعرض fallback عربي نظامي. المظهر النهائي بخطيCairo/Manrope يحتاج مراجعة عند التشغيل المتصل.
